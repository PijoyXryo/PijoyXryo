#### 🔧 Featured project: [stm32-bare-metal](https://github.com/PijoyXryo/stm32-bare-metal)
Register-level drivers for the STM32F407 (Cortex-M4), written straight from the reference manual. There is no HAL and no vendor libraries.
- Custom startup code, vector table and linker script, written in C with no assembly
- USART2 driver, with interrupt-driven RX + ring buffer, GPIO and SysTick in progress
- Runs and is verified in the **Renode** simulator, so anyone can try it without a board
